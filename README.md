nothing fancy, just a very small mod for Among Us that does one thing and one thing only. lets you end meetings or games immediately.  Useful for getting out of troll button meetings, or ending glitched meetings or games.

IF you also have my [banlist mod](https://github.com/katzklaw/banlist) this mod cooperates with the moderator system from that mod to allow your chosen moderators to end meetings if needed(not games. that is still on you as the host).

usage:  
/em or /endmeeting - immediately ends the meeting as if everyone skipped
/eg or /endgame - immediately ends the game as "impostor disconnect"

please do not use this to troll. 😩
